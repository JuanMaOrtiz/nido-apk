# Nido

El instalable de **Nido**, una pantalla de inicio rápida y sin publicidad para Android TV y Google TV (Android 9 o más nuevo).

## Link fijo (siempre la última versión)

```
https://github.com/JuanMaOrtiz/nido-apk/releases/latest/download/Nido.apk
```

## Instalar con Downloader

1. En la tele, instalá **Downloader** desde Play Store.
2. Dale permiso para instalar apps: Configuración → Preferencias del dispositivo → Seguridad y restricciones → Fuentes desconocidas → Downloader.
3. Abrí Downloader, poné el link de arriba e instalá.
4. Abrí **Nido**: el asistente te guía (depuración, activar Nido, ciudad, estante, clave de TMDB desde el celular).

Una vez instalado, Nido se actualiza solo.
